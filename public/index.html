How to read this board
DecisionPLAY is a recommended prop. WATCH means the model sees a directional edge, but the full profile is not strong enough for a PLAY.
Confidencev14's estimated confidence in the MORE or LESS direction. It is model confidence, not a guarantee of the outcome.
TierPriority within the model's recommendation set. CORE is the strongest overall profile, SECONDARY is a solid qualifying setup, and LEAN is a lower-priority directional read.
History SignalResearch-only check of how the pitcher has performed versus prior posted K lines. Positive supports v14; negative conflicts. It does not change the pick.
What's inside Reason? The detailed reason shows the inputs behind the recommendation:
  • Projection / edge — projected strikeouts versus today's posted line.
  • Form — recent strikeout production such as L3, L5 and L10 starts.
  • Volume — batters faced, pitch count and starter workload/role.
  • Opponent — opponent strikeout rates, recent splits and the blended matchup estimate.
  • Same opponent — prior starts against this opponent when available; informational only.
  • Calibration — how similar historical model recommendations performed; used as supporting context.
